# GN Innovates — AI Lead Generation, Qualification, Booking & Follow-Up System

This repository will hold the AI-powered client-acquisition system for **GN Innovates**
(George Nabil) — a focused sales-assistance system, not a generic chatbot. It captures
leads, qualifies them through an AI intake assistant, scores and routes them to the
correct service, drives qualified leads to a paid booking, and runs consented,
George-approved follow-up until they book or decline.

## Status: Phase 1 — Architecture & Discovery

No application code has been written yet. Nothing has been purchased, connected, or
sent live. The full architecture plan, technology recommendations, cost estimates,
data model, and the list of decisions/credentials needed from George live in:

**[`docs/phase-1-architecture-plan.md`](docs/phase-1-architecture-plan.md)**

That document is currently pending George's review and approval before any paid
integration is implemented or any code is written.

## Planned phases

| Phase | Scope |
|---|---|
| 1 | Architecture and requirements *(this phase)* |
| 2 | Database, CRM, and admin dashboard |
| 3 | Lead forms and AI qualification |
| 4 | Booking and payment workflow |
| 5 | Email and SMS follow-up |
| 6 | Analytics and reporting |
| 7 | Testing, security review, and deployment |

Each phase implements only its approved scope, is tested, and is presented for
verification before moving to the next. Paid services and live (non-test) message
sending are not activated until explicitly approved.
